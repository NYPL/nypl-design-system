## Overview

These components are directly exported from Chakra UI. The `Center`, `Circle`,
and `Square` are layout component that center their child.

Available props can be found on Chakra's [Style Props](https://v2.chakra-ui.com/docs/styled-system/style-props)
guide.

## Center

{

<Box mt="s" mb="s">
  Some text at the beginning.
  <Center p="s" bg="brand.primary" color="ui.white">
    This text is centered inside a `Center` component.
  </Center>
  Some text at the end.
</Box>
}

{

<Center border="1px solid" borderColor="ui.gray.medium">
  <Image
    alt="Centered Image"
    size="medium"
    src={getPlaceholderImage("smaller")}
  />
</Center>
}

## Circle

This component is similar to the `Center` component but it is always rendered as
a circle.

{

<HStack spacing="s">
  <Circle size="50px" bg="brand.secondary">
    <Icon name="download" color="ui.white" size="large" />
  </Circle>
  <Circle size="50px" bg="ui.link.primary">
    <Icon name="check" color="ui.white" size="large" />
  </Circle>
</HStack>
}

## Square

This component is similar to the `Circle` component but always has equal height
and width.

{

<HStack spacing="s">
  <Square size="50px" bg="brand.secondary">
    <Icon name="download" color="ui.white" size="large" />
  </Square>
  <Square size="50px" bg="ui.link.primary">
    <Icon name="check" color="ui.white" size="large" />
  </Square>
</HStack>
}
