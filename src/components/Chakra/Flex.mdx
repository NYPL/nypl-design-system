## Overview

`Flex` is directly exported from Chakra UI. It's useful for simple layouts and
can be used along with Chakra's `Spacer` component to create a container where
the children span the entire width.

Details about available props and related child components can be found on Chakra's
[Flex component](https://v2.chakra-ui.com/docs/components/flex/usage) page.

{

<Flex alignItems="baseline" mb="s">
  <Box w="20" h="20" bg="brand.primary" />
  <Box w="20" h="20" bg="brand.secondary" />
  <Box w="20" h="20" bg="brand.primary" />
  <Box w="20" h="20" bg="brand.secondary" />
  <Box w="20" h="20" bg="brand.primary" />
</Flex>
}

## Examples

Use the `justify` prop to move the children around.

{

    </Flex>
  </div>
</VStack>
}

## With `Spacer`

`Spacer` helps to display a row with two children where the first aligns
left and the second aligns right.

{

<Flex alignItems="baseline">
  <Logo name="nyplFullBlack" size="small" />
  <Spacer />
  <Button variant="callout">Donate</Button>
</Flex>
}

This is similar to setting `justify="space-between"` on the `Flex` parent, but
`Spacer` is more flexible for most situations.
