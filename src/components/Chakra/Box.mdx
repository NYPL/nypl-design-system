## Overview

`Box` is directly exported from Chakra UI. It's a simple and composable component
that can be used for many situations. By default, it renders a `div`, but can
render another element using the `as` prop.

Available props can be found on Chakra's [Style Props](https://v2.chakra-ui.com/docs/styled-system/style-props)
guide.

{

<Box borderWidth="2px" padding="s" borderRadius="lg" overflow="hidden">
  <Box p="s" bg="brand.primary" color="ui.white">
    This text is inside a `Box` component.
  </Box>
</Box>
}

In the example above, the padding, background color, and text color are
updated with the `p`, `bg`, and `color` props respectively.

## With `VideoPlayer` component

In this example, the props added to the `Box` component are `borderWidth`,
`padding`, `borderRadius`, and `overflow` to create a wrapper around the
`VideoPlayer` component.

{

<Box borderWidth="2px" padding="s" borderRadius="lg" overflow="hidden">
  <VideoPlayer
    videoId="nm-dD2tx6bk"
    videoType="youtube"
    aspectRatio="sixteenByNine"
  />
</Box>
}
