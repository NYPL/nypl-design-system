## Overview

`Stack`, `HStack`, and `VStack` are directly exported from Chakra UI. They are
layout components that make it easy to stack elements together with spacing if
desired.

More information can be found on the Chakra [Stacks](https://v2.chakra-ui.com/docs/components/stack/usage)
page.

In the following examples, Design System `Icon` components are wrapped in Chakra's
`Circle` component.

## Stack

The `Stack` component can stack elements both horizontally and vertically through
the `direction` prop and the `"row"` and `"column"` values, respectively. You can
also use Chakra's responsive syntax to change the direction at certain breakpoints.

<Source
  code={`
  <Stack align="right" direction={{ sm: "column", md: "row" }} spacing="s">
    //...
  </Stack>
`}
  language="tsx"
/>

{

<Stack direction={{ sm: "column", md: "row" }} spacing="s">
  <Circle size="50px" borderColor="ui.black" borderWidth="1px">
    <Icon name="errorFilled" size="large" />
  </Circle>
  <Circle size="50px" borderColor="ui.black" borderWidth="1px">
    <Icon name="errorOutline" size="large" />
  </Circle>
  <Circle size="50px" borderColor="ui.black" borderWidth="1px">
    <Icon name="check" size="large" />
  </Circle>
</Stack>
}

## HStack

`HStack` stacks components horizontally. This is the same as the `Stack` component
with a `direction` of `"row"`.

{

<HStack spacing="s">
  <Circle size="50px" borderColor="ui.black" borderWidth="1px">
    <Icon name="errorFilled" size="large" />
  </Circle>
  <Circle size="50px" borderColor="ui.black" borderWidth="1px">
    <Icon name="errorOutline" size="large" />
  </Circle>
  <Circle size="50px" borderColor="ui.black" borderWidth="1px">
    <Icon name="check" size="large" />
  </Circle>
</HStack>
}

## VStack

`VStack` stacks components vertically. This is the same as the `Stack` component
with a `direction` of `"column"`.

{

<VStack spacing="s">
  <Circle size="50px" borderColor="ui.black" borderWidth="1px">
    <Icon name="errorFilled" size="large" />
  </Circle>
  <Circle size="50px" borderColor="ui.black" borderWidth="1px">
    <Icon name="errorOutline" size="large" />
  </Circle>
  <Circle size="50px" borderColor="ui.black" borderWidth="1px">
    <Icon name="check" size="large" />
  </Circle>
</VStack>
}
