## Overview

<Description of={HorizontalRuleStories} />

The `HorizontalRule` component renders a basic `<hr>` element. While not
explicit props, the `height` and `width` values can be customized. For the
`height` style prop, use a whole number, a `px` value, a `em` value, or a `rem`
value. Otherwise, the default value of `"2px"` will be used.

## Component props

`HorizontalRule` composes a Chakra `Box` component, so you may pass
any Chakra `Box` props, as well as the props below.

## Accessibility

The `HorizontalRule` component is not just a visual thematic break between
content or interfaces, it is also picked up by screenreaders. Internally, the
`HorizontalRule` component uses the `<hr>` element which has a `role` of
`"separator"`.
