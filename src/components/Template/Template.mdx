## Overview

- The `Template` component is used to render the general structure of a page
- The `Template` child components should be used to compose the basic page
  layout
- The child components adhere to NYPL design standards and provide a consistent
  mobile and desktop layout

<Source
  code={`
import {
  Template,
  TemplateBreakout,
  TemplateFull,
  TemplateSidebar,
  TemplateMain,
} from "@nypl/design-system-react-components";
//...
<Template sidebar="...">
  <TemplateBreakout>...</TemplateBreakout>
  <TemplateFull>...</TemplateFull>
  <TemplateSidebar>...</TemplateSidebar>
  <TemplateMain>...</TemplateMain>
  <TemplateFull>...</TemplateFull>
</Template>
`}
  language="jsx"
/>

## Accessibility

### Content Width

Wide lines of text with more than 80 characters per line are difficult to read
and are proven to make it harder for people to focus, while short lines of text
with fewer than 30 characters per line force the eye to travel back too often,
breaking a reader's rhythm.

The `TemplateMain` component has a max width of `1280px`, which is much wider
than the ideal line length for standard text. When page content is predominantly
large blocks of text, the `Template` component should be set to use the `narrow`
variant to restrict the width of the `TemplateMain` component.

### DOM Structure and Skip Navigation

The `TemplateMain` component renders the content as a `<main>` element with a
default `id` of `"mainContent"`. This should be used as the anchor element for
the skip navigation link. If an application is using the current NYPL `Header`,
it already contains the skip navigation feature. Just make sure it is pointing
to the correct anchor element.

Resources

- [WebAim Skip Navigation Link](https://webaim.org/techniques/skipnav/)
- [A11ymatters Skip Navigation Link](https://www.a11ymatters.com/pattern/skip-link/)

offered:

- `TemplateBreakout`

## Understanding the Fluid Layout

- When using the `sidebarLeft` or `sidebarRight` layout variants,
  `TemplateSidebar` and `TemplateMain` use fluid sizing where each fills a
  fraction of the full width
- Width fractions are dependent on viewport
- Content in `TemplateMain`, especially grids, should adhere
  to the <Link href="/?path=/docs/style-guide-responsive-grid--docs">
  responsive grid</Link> recommendations and patterns
