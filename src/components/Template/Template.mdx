## Overview

- The `Template` component is used to render the general structure of a page
- The `Template` child components should be used to compose the basic page
  layout
- The child components adhere to NYPL design standards and provide a consistent
  mobile and desktop layout

<Source
  code={`
  import {
    Template,
    TemplateBreakout,
    TemplateContent,
    TemplateFooter,
    TemplateFull,
    TemplateHeader,
    TemplateMain,
    TemplateSidebar,
  } from "@nypl/design-system-react-components";
  //...
  <Template variant="...">
    <TemplateHeader>...</TemplateHeader>
    <TemplateFull>...</TemplateFull>
    <TemplateMain>
      <TemplateFull>...</TemplateFull>
      <TemplateSidebar>...</TemplateSidebar>
      <TemplateContent>...</TemplateContent>
      <TemplateBreakout>...</TemplateBreakout>
      <TemplateFull>...</TemplateFull>
    </TemplateMain>
    <TemplateFull>...</TemplateFull>
    <TemplateFooter>...</TemplateFooter>
  </Template>
`}
  language="tsx"
/>

## Accessibility

### Content width

When used without a sidebar, the `TemplateContent` component has a max width of
`1280px`, which is much wider than the ideal line length for standard text. When
page content is predominantly large blocks of text, the `Template` component
should be set to use the `narrow` variant to restrict the width of the
`TemplateContent` component.

### DOM structure and skip navigation

The `TemplateMain` component renders the content in a `<main>` element. It is
recommended to add an `id` of `"mainContent"` to the `TemplateMain` component to
be used as the anchor element for the skip navigation link. If an application is
using the current NYPL `Header`, it already contains the skip navigation
feature. Just make sure it is pointing to the correct anchor element.

If more granular control of the skip navigation feature is needed, the target
`id` can be added to one of the organizational child components (see below)
instead of the `TemplateMain` component.

Resources

- [WCAG 2.1: Success Criterion 1.4.8 Visual Presentation](https://www.w3.org/TR/WCAG21/#visual-presentation)
- [WebAim Skip Navigation Link](https://webaim.org/techniques/skipnav/)
- [A11ymatters Skip Navigation Link](https://www.a11ymatters.com/pattern/skip-link/)

## Understanding the fluid layout

- When using the `sidebarLeft` or `sidebarRight` layout variants,
  `TemplateSidebar` and `TemplateContent` use fluid sizing where each fills a
  fraction of the full width
- Width fractions are dependent on viewport
- Content in `TemplateContent`, especially grids, should adhere
  to the <Link href="/?path=/docs/style-guide-responsive-grid--docs">
  responsive grid</Link> recommendations and patterns
