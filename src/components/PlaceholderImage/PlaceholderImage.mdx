## Overview

The `PlaceholderImage` component is displayed whenever a viable image is not
available. The placeholder includes an icon representing the image's `contentType`
and an inline message that reads "Preview not available."

## Component Props

`PlaceholderImage` composes an HTML `div` element, so you may pass any HTML `div`
attributes, as well any Chakra style props and the props below.

<ArgTypes of={PlaceholderImageStories.WithControls} />

## Accessibility

The icon representing `contentType` is decorative and is automatically hidden from
assistive technology.

When possible, pass a specific `contentTitle` that specifically describes the
missing content (e.g. a book's title), especially when multiple `PlaceholderImage`s
are rendered, as in a grid. This text is used to provide context to screen reader
users.

<Source
  code={`
  <Grid templateColumns="repeat(3, 1fr)" gap="grid.m">
    <GridItem>
      <PlaceholderImage
        contentType="book"
        contentTitle="Moby Dick by Herman Melville"
      />
    </GridItem>

## Using width

The `PlaceholderImage` component's size is determined by the width of its container,
or a particular `width` passed directly to the component as a prop. It will
automatically adjust to fit the available space while maintaining its aspect ratio.

## Responsive Sizing

Since `PlaceholderImage` fills whatever container it's placed in while preserving
its `aspectRatio`, it naturally resizes responsively when used inside fluid
layouts like `Grid`. It uses container queries, rather than viewport breakpoints,
to scale its icon and caption, so below a 200px width container the "Preview not
available" text is visually hidden (though still exposed to screen readers) to
avoid crowding very small placeholders.
