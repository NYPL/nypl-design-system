## Overview

The `Menu` component renders a collection of button and/or link elements within a
dropdown menu format. The component allows users to perform multiple actions
from an element with a small footprint.

## Component props

The `Menu` composes a Chakra `Box` component, so you may pass any Chakra `Box`
props, as well as the props below.

## Accessibility

When the menu is open, the menu items are keyboard accessible with the
`ArrowDown` and `ArrowUp` keys, but not tabbable. The focus indicator is the
gray background and bolded text. The `Enter` key, or a click, selects an item
and closes the menu. The menu can also be closed with a click outside of its
container or the `Escape` key.

After a list action item is clicked, consuming apps should be mindful of the
action that is performed by the action item's onClick handler and adjust the
focus accordingly.

The menu itself requires a label to provide meaningful accessible text, even
when only the vertical ellipsis is used instead of a visible label.

Resources:

- [MDN Menu accessibility](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Roles/menu_role)

## Menu types

There are four types:

- button
- text button
- icon (with container)
- icon (without container)

These types are toggled with `showLabel` and `showBorder` props. Use the icon
type when there is limited space such as a table or on mobile.

## Menu label

The default label of the menu will be `labelText`. With `showSelectionAsLabel`
enabled, the selected item will then display as the menu's label. This is useful
when the choice
should be displayed after selection, like choosing sort/filter criteria, or if
an option needs to be selected and displayed when the page first loads.

`labelText` is still required even if `showSelectionAsLabel` is true, because it
is used for the `aria-label`.

## Menu content

Menu items can be displayed with images, icons, or just as text. They can be
grouped with headings, dividers, or both.

The menu can be aligned to the left or right by its consuming app.

The maximum height of the menu list container is `320px`, or roughly eight menu
items. Past that height, it will scroll. The maximum width is `300px`. Past that
width, menu items will wrap onto the next line.

Content is passed to the menu through `listItemsData`, and each menu item needs
to be one of three types: `action`, `group`, or `divider`. Each type expects
different properties, as shown below:

<Source
  code={`
  const exampleListItemsData = [
    {
      type: "group",
      id: "group-1",
      label: "I'm group 1",
      children: [
        {
          type: "action",
          id: "item-title-1",
          label: "I'm item 1",
          onClick: () => {
            console.log("Item Title 1 clicked");
          },
        },
        {
          type: "action",
          id: "item-title-2",
          label: "I'm item 2",
          onClick: () => {
            console.log("Item Title 2 clicked");
          },
        },
      ],
    },
    { type: "divider", id: "divider-1" },
    {
      type: "action",
      id: "item-title-3",
      label: "I'm item 3",
      onClick: () => {
        console.log("Item Title 3 clicked");
      }
    },
  ];
  // ...
  <Menu labelText="Menu" listItemsData={exampleListItemsData} />
`}
  language="tsx"
/>

All `action` objects require an `onClick` function. The `media` prop is
optional and will display to the left of the menu text, and will render either
an [Icon](./?path=/docs/components-media-icons-icon--docs) or
[Image](./?path=/docs/components-media-icons-image--docs). The `media` prop
requires a `type` property (icon or image) and then either the name of the icon
or the source URL and alt text of the image.

<Source
  code={`
  // Example of action item with icon
  {
    type: "action",
    id: "item-title-1",
    label: "I have an icon",
    media: { type: "icon", name: "search" },
    onClick: () => {
      console.log("Item Title 1 clicked");
    },
  },
  // Example of action item with image
  {
    type: "action",
    id: "item-title-2",
    label: "I have an image",
    media: { type: "image", src: "//loremflickr.com/300/300/new+york+public+library", alt: "" },
    onClick: () => {
      console.log("Item Title 2 clicked");
    },
  }
`}
  language="tsx"
/>
