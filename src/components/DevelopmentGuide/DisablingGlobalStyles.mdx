## Global Styles

By default, the `DSProvider` will add CSS reset rules and [global base styles](https://github.com/NYPL/nypl-design-system/blob/development/src/theme/foundations/global.ts) defined in the DS.

These styles build on [Chakra's CSS reset](https://github.com/chakra-ui/chakra-ui/blob/%40chakra-ui/react%401.8.8/packages/css-reset/src/css-reset.tsx)
rules and affect the native HTML `body`, `a`, `svg`, `button`, `select`, `input`, `textarea`, and `iframe`.
These rules help help normalize the appearance of elements across browsers and applications.

<Source
  code={`
  <DSProvider>
    <div className="my-app">
      {children}
    </div>
  </DSProvider>
`}
  language="tsx"
/>

## Disabling Styles

**We recommend not disabling the CSS reset rules and to include global styles.**
If you think your app may require disabling either or both, please reach out to
the DS team to discuss.

There are situations where you may want to disable these global styles. For
example, the NYPL `Header` app is a DS-based application that is rendered on top
of other applications and websites. These digital products _may_ not be built
with the DS and, therefore, the global base styles of the application may
conflict with the styles of the DS.

In order to disable the CSS reset rules, set the `resetCSS` prop to `false`. In
order to disable the global styles, set the `disableGlobalStyles` prop to `true`.

<Source
  code={`
  <DSProvider resetCSS={false} disableGlobalStyle>
    <div className="my-app">
      {children}
    </div>
  </DSProvider>
`}
  language="tsx"
/>
