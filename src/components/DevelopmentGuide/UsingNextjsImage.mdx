## Objectives and goals

Based on [Image performance: DC Phase
2](https://docs.google.com/document/d/1hZsnSOmKFQFtAaNAWjZ9pd44m6wYygn_bUaeDNyrPr0/edit?tab=t.0#heading=h.9wuc905l6iod)
in the DAM team, there is no perceivable or metric-based reason to use the
Reservoir `Image` component over the Next.js `Image` component. Conversely,
using the Next.js `Image` component provides advantages including, but not
limited to:

- The Next.js `Image` component is meant to optimize image performance within
  the Next.js framework.
- The Next.js team works with the Chrome browser team to optimize their
  components. This means better maintenance and optimization from Next.js that
  the Reservoir team and NYPL Digital as a whole cannot readily provide.
- Using the Next.js `Image` component brings NYPL apps deeper into the Next.js
  ecosystem, which could allow framework-specific optimizations in the future.

While the Next.js `Image` component offers optimization and some enhanced
styling features, the Reservoir `Image` component has functionality that is not
included in the Next.js `Image` component. Specifically, the Reservoir `Image`
component offers functionality to set the image aspect ratio in conjunction with
cropping and custom sizing.

**Based on the benefits and advantages of the Next.js `Image` component, NYPL
Engineering recommends utilizing the Next.js `Image` component over the
Reservoir `Image` component.** This document will offer recommendations for
configuring the Next.js `Image` component to implement the features available in
the Reservoir `Image` component.

## Recommendations

The following recommendations can be used to recreate specific functionality
found in the Reservoir `Image` component.

### Aspect ratio

To set the aspect ratio for the overall footprint of an image, the Next.js `Image`
component needs to be wrapped in a parent `div` with specific position and
`paddingBottom` CSS attributes applied. The Next.js `Image` component itself will
then require the `objectFit` CSS attribute.

To execute a specific aspect ratio, the `paddingBottom` value needs to be a
percentage derived from the h/w (height over width) fraction. For example, to
attain a four-by-three aspect ratio, the `bottomPadding` value should be set to
75%, which comes from 3/4 (three over four).

<Source
  code={`
<div
    style={{
      background: "ui.black",
      position: "relative",
      paddingBottom: "75%",
    }}
  >
    <Image
      alt="Big Ben and Parliament"
      fill={true}
      src="/images/bigben.jpg"
      style={{
        objectFit: "contain",
      }}
    />
</div>
`}
  language="jsx"
/>

### Cropping

In the aspect ratio examples above, the default behavior results in a
"contained" image, where the overall footprint takes on the specified aspect
ratio while the actual image retains its original aspect ratio and is resized to
fit within the overall container.

An image can be cropped to fill the overall footprint by setting the value of
the `objectFit` CSS attribute to `"cover"`. In the previous examples, the
`objectFit` CSS attribute was set to `"contain"`.

<Source
  code={`
<div
    style={{
      background: "ui.black",
      position: "relative",
      paddingBottom: "100%",
    }}
  >
    <Image
      src="/images/bigben.jpg"
      alt="Big Ben and Parliament"
      fill={true}
      style={{
        objectFit: "cover",
      }}
    />
</div>
`}
  language="jsx"
/>

### Cropping with focal point

When using the `objectFit` method for cropping images, by default images are
cropped with the center of the image as the focal point. The focal point for
cropping can be adjusted by adding the `objectPosition` attribute in conjunction
with the `objectFit` attribute.

<Source
  code={`
<div
    style={{
      background: "ui.black",
      position: "relative",
      paddingBottom: "100%",
    }}
  >
    <Image
      src="/images/bigben.jpg"
      alt="Big Ben and Parliament"
      fill={true}
      style={{
        objectFit: "cover",
        objectPosition: "top",
      }}
    />
</div>
`}
  language="jsx"

### Custom width

By default, these recommendations for the Next.js `Image` component will set an
image to fill the width of its parent container. To set a specific width, an
additional DOM layer will be necessary with an appropriate `width` CSS attribute
applied.

<Source
  code={`
<div
    style={{
      width: "256px",
    }}
  >
    <div
      style={{
        background: "ui.black",
        position: "relative",
        paddingBottom: "100%",
      }}
    >
      <Image
        src="/images/bigben.jpg"
        alt="Big Ben and Parliament"
        fill={true}
        style={{
          objectFit: "cover",
        }}
      />

</div>

### Component

<Source
  code={`
import React, { CSSProperties } from "react";
import Image, { ImageProps } from "next/image";
const aspectRatioValues = {
    fourByOne: "25%",
    twoByOne: "50%",
    sixteenByNine: "56.25%",
    fourByThree: "75%",
    oneByOne: "100%",
    square: "100%",
    oneByTwo: "200%",
};
export const aspectRatioArray = [
    "fourByOne",
    "twoByOne",
    "sixteenByNine",
    "fourByThree",
    "oneByOne",
    "square",
    "oneByTwo",
] as const;
export type AspectRatioType = (typeof aspectRatioArray)[number];
const widthValues = {
    auto: "auto",
    xs: "64px",
    sm: "96px",
    md: "128px",
    lg: "160px",
    xl: "256px",
    "2xl": "320px",
    "3xl": "640px",
};
export const widthArray = ["xs", "sm", "md", "lg", "xl", "2xl", "3xl"] as const;
export type WidthType = (typeof widthArray)[number];
export const focalPointArray = ["top", "bottom", "left", "right"] as const;
export type FocalPointType = (typeof focalPointArray)[number];
export interface CustomImageProps extends ImageProps {
    aspectRatio?: AspectRatioType;
    backgroundColor?: CSSProperties["color"];
    border?: CSSProperties["border"];
    cropFocalPoint?: FocalPointType;
    customWidth?: WidthType;
    isCropped?: boolean;
}
const CustomImage = (props: CustomImageProps) => {
    const {
      alt,
      aspectRatio = "square",
      backgroundColor = "#000000",
      border = "1px solid #333",
      cropFocalPoint = undefined,
      customWidth = "auto",
      isCropped = false,
      src,
      ...rest
    } = props;
    return (
      <div style={{ width: widthValues[customWidth] }}>
        <div
          style={{
            background: backgroundColor,
            border: border,
            position: "relative",
            paddingBottom: aspectRatioValues[aspectRatio],
          }}
        >
          <Image
            src={src}
            alt={alt}
            fill={true}
            style={{
              objectFit: isCropped ? "cover" : "contain",
              objectPosition: isCropped ? cropFocalPoint : undefined,
            }}
            {...rest}
          />
        </div>
      </div>
    );
};
export default CustomImage;
`}
  language="jsx"
/>

## Additional Recommendations

For improved function and optimization, the NYPL Digital front-end development
team recommends utilizing the following props on the Next.js `Image` component.

### onError

- If the source image fails to load (e.g., a 404), this fallback logic triggers.
- Can set `imageSrc` to a default image and log the error.
- Does cause a re-render with the fallback image.

### placeholder

- Instead of a `SkeletonLoader`, the `placeholder` prop can be set to render a
  low-resolution placeholder (either a blurred version of the intended image or
  a custom image) as the image loads.
- Helpful to differentiate between the loading state of the image and the error
  state (so the `onError` fallback should not be the same as the `placeholder`
  prop).

### quality

- The quality of the optimized image, an integer 1-100.
- The quality defaults to 75.

### sizes

- Next's version of an internal media query to check the width of the viewport
  and pick size of the image accordingly.
- Can be used in combination with an outer styling `div` or setting `style` on the
  image.
- Optimizes loading time for responsively styled images since you're telling the
  browser which size to pick.
- If you don't specify a `sizes` value in an image with the `fill` property, a
  default value of `"100vw"` (full screen width) is used.

<Source
  code={`
sizes="(max-width: 480px) 100vw, (max-width: 1024px) 50vw, 25vw"
`}
  language="jsx"
/>

In the example above:

- If viewport width ≤ `480px` → image uses `100%` of viewport width.
- If viewport width ≤ `1024px` → image uses `50%` of viewport width.
- Otherwise → image uses `25%` of viewport width.
