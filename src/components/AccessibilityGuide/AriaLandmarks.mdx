## ARIA roles

ARIA roles on a web page add meaning to content, particularly non-semantic HTML elements like `div` or `span`. For example, a `form` element does not need `role="form"`, but a `div` might need `role="main"` or `role="input"` to distinguish what it represents on the page.

## ARIA landmarks

Landmarks can be a useful tool for people who use screen readers to orient themselves to important areas of a web page, and help quickly navigate to these areas within a website or application.

ARIA’s 8 landmark roles are specifically meant to describe page organization and structure, providing keyboard navigation to each larger section. Each of these roles has a corresponding native HTML element:

| Landmark role | HTML element        |
| ------------- | ------------------- |
| banner        | document `<header>` |
| complementary | `<aside>`           |
| contentinfo   | document `<footer>` |
| form          | `<form>`            |
| main          | `<main>`            |
| navigation    | `<nav>`             |
| region        | `<section>`         |
| search        | `<search>`          |
