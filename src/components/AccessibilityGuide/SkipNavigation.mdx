## General Information

An application's "skip navigation" is usually a link used to skip to the main
content of a page. It is visually hidden until a user focuses on it.

In the case of NYPL applications, the skip navigation contains two links; the
first points to the main content of the page (the `"#mainContent"` anchor) and
the second points to accessibility information on [NYPL.org/accessibility](https://nypl.org/accessibility).

The `"#mainContent"` anchor is an element with an `id` of `"mainContent"`. The
`TemplateMain` component renders as a `<main>` HTML element, but you must add
an `id` of `"mainContent"` to connect it with the skip navigation. While it's
possible to update the target of the skip link and the id of the `<main>` element,
this is not recommended.

The [NYPL Header](https://github.com/NYPL/nypl-header-app) automatically renders a
skip navigation area with links. Reservoir also offers a standalone `SkipNavigation`
component that can be used with the `Template` components.
