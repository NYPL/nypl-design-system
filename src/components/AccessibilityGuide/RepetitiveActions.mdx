## General Information

To navigate a website, screen reader users often tab through – or pull up a list of –
all the buttons and links on a page. When button labels and link text are not unique,
it becomes difficult to determine their purpose or destination. For example, if you
have multiple "read more" links, the user has to examine surrounding content to
understand the link's destination.

## Unique Button Labels and Link Text

Button labels and link text should generally be unique on any given page to aid
navigation for screen reader users.

In cases where visible text can't be changed, additional context can be provided in
several ways, including:

- adding additional text within the button or link, but hiding it off-screen so
  sighted users will not perceive it, but it will be picked up by screen reader
  software
- using an `aria-label` to override visible text
- using `aria-labelledby` to add to visible text by referencing both the
  link itself and another element that will add more descriptive text

For example, a link that is visibly titled "Read more" can:

- include `<span class="sr-only">about jobs</span>` after the visible text
  within the link where `sr-only` is a custom class with styles to position the
  `<span>` element off-screen
- add the `aria-label` attribute with complete descriptive text
- add the `aria-labelledby` attribute with references to multiple element IDs,
  including the link itself and another more descriptive piece of text, such as
  a nearby heading, resulting in a label such as "read more about jobs"

### Examples:

#### sr-only

<Source
  code={`
  <style>
    .sr-only {
      clip: rect(1px, 1px, 1px, 1px);
      height: 1px;
      overflow: hidden;
      position: absolute !important;
      width: 1px;
      word-wrap: normal;
    }
  </style>
  <a href="..." id="link1">
    Read more <span class="sr-only">about jobs</span>
  </a>
`}
  language="html"
/>

#### aria-label

<Source
  code={`
  <a href="..." id="link1" aria-label="read more about jobs">
    Read more
  </a>
`}
  language="html"
/>

#### aria-labelledby

<Source
  code={`
  <h2 id="jobsheading">Jobs</h2>
  ...
  <a href="..." id="link1" aria-labelledby="link1 jobsheading">
    Read more
  </a>
`}
  language="html"
/>
