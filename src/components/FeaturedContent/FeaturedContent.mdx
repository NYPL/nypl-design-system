## Overview

<Description of={FeaturedContentStories} />

`FeaturedContent` is a full-width container that visually emphasizes an image and
text block.

Its responsive styles are applied using [container queries](../?path=/docs/development-guide-container-query-guide--docs)
rather than media queries.

## Component props

`FeaturedContent` composes a Chakra `Box` component, so you may pass
any Chakra `Box` props, as well as the props below.

## Accessibility

The `FeaturedContent` component combines a text block and an image. The text
block (`textContent`) can be any JSX element, so child elements should follow
accessibility requirements.

All images must have an `alt` attribute. The `alt` prop should be used to
concisely describe the image. If the image is decorative, then the `alt` prop
should be an empty string `""`.

Resources for text accessibility:

- [Chakra UI Text](https://chakra-ui.com/docs/components/typography/text)

Resources for image accessibility:

- [W3C WAI Images Tutorial](https://www.w3.org/WAI/tutorials/images/)
- [WebAIM Accessible Images](https://webaim.org/techniques/images/)
- [Yale Usability & Web Accessibility](https://usability.yale.edu/web-accessibility/articles/images)

## Component width variations

`FeaturedContent`'s width is controlled using the `isFullWidth` prop. The default
is `false`, which causes the component to fill only its parent. If `isFullWidth = true`,
the component will break out of its container and fill the screen's width
(max 1280px). This full layout is best viewed on a full screen, not as shown below.

<Canvas of={FeaturedContentStories.LayoutVariations} />

## Image position variations

The image position can be rendered through the `imageProps.position` prop. The
default is `end`, meaning the image will appear after the text block in a row
and below in a column. The other option is `start`, where the image will appear
before the text block in a row above it in a column.

<Canvas of={FeaturedContentStories.ImagePositionVariations} />

## Image width variations

`FeaturedContent`'s image width can be changed using the `imageProps.width`
prop. The options for width are `oneQuarter`, `oneThird`, `oneHalf`, `twoThirds`,
and `threeQuarters`. The default width is `oneHalf`.

<Canvas of={FeaturedContentStories.imageWidthVariations} />

## Text content

`textContent` is a string or JSX element passed into `FeaturedContent`.
Accessibility standards and spacing should be considered independently of the
`FeaturedContent` styling.

The above example, with an overline, a heading, a short paragraph of body text,
and a CTA button, is the recommended usage. While other configurations are
possible, keep in mind that the minimum height of the component is `320px` and it
is best to avoid excessive white space.
