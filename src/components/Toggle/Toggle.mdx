## Overview

`Toggle` is commonly used as an “on/off” switch to perform a binary action that
occurs immediately after a user “flips the switch.”

It can display a label and helper/error text. The label should be short and to
the point, often three words or less, and clarify the action being performed.

## Component Props

The `Toggle` composes an HTML `input` element, so you may pass any HTML `input`
attributes, as well any Chakra style props and the props below.

`Toggle` is built on top of Chakra UI's `Switch` component. Although certain
accessibility guidelines suggest a `<button>` element for toggles, Chakra's
`Switch` internally uses a checkbox. We chose this implementation due to its
comprehensive styling options and robust state management.

For comparison and reference, resources that build toggle components with the
`<button>` element are linked below.

Resources:

- [Chakra UI Switch](https://chakra-ui.com/docs/components/form/switch)
- [W3C Switch Example Using HTML Button](https://w3c.github.io/aria-practices/examples/switch/switch-button.html)
- [Inclusive Components Toggle Buttons](https://inclusive-components.design/toggle-button/)
- [Accessible HTML Toggle Button (Switch)](https://www.erikkroes.nl/blog/accessible-html-toggle-button-switch/)

## Controlled Toggle

The `isChecked` prop must be controlled by the parent component. The
`onChange` function will be called every time the `isChecked` prop changes.

<Source
  code={`
  const [isChecked, setIsChecked] = useState(false)
  const onChange = (e) => {
    // This will return the value through the event object.
    setIsChecked(e.target.value)
    console.log(e.target.value);
  };
  <Toggle
    id="toggle"
    isChecked={isChecked}
    labelText="Controlled Toggle"
    onChange={onChange}
/>
`}
  language="jsx"
/>
