The `total results` heading reflects the current state of a results set by
displaying the number of records, the current position, and, if applicable, the search term used to generate the set.

## Rendering

The `total results` heading should be rendered using the DS
[Heading](./?path=/docs/components-typography-styles-heading--docs) component.

## Position

The `total results` heading should be positioned below the `active filters` list and
aligned to the left.

## Updating

The `total results` heading should be updated whenever filters are applied.

## Formatting

The `total results` heading should use the following format:

`Displaying 1-24 of 1,234 results`

In use cases where a keyword search term has been applied to the search results
using the `keyword search` field, the `total results` heading should use the
following format:

`Displaying 1-24 of 567 results for "{search_term}"`
