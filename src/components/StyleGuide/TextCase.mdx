## General guidance

All text elements, unless otherwise specified, should use sentence case where
only the first letter of the first word in a phrase is capitalized. This
includes, but is not limited to, page titles, headings, labels, menu items,
navigation components, and button labels.

When using sentence case, don't put a period at the end of a title or heading.

## Title case

Title case should only be used for official names and proper nouns. This usually
includes product names, brands, and titles of books. This also applies to
special terms that are always formatted using title case.

## All uppercase

Don't use all-uppercase, except in the following contexts:

- in official names
- in abbreviations that are always written in all-caps
- when referring to code that uses all-caps
