## General guidance

All text elements&mdash;including, but not limited to, page titles, headings,
labels, menu items, navigation components, and buttons&mdash;should use sentence
case where only the first letter of the first word in a phrase is capitalized.

When using sentence case, don't put a period at the end of a title or heading.

This guidance for sentence case applies to all text unless otherwise specified.

## Title case

Title case should only be used for official names and proper nouns. This usually
includes product names, brands, and titles of books. This can also apple to
special terms that are always formatted using title case.

## All uppercase

Don't use all-uppercase, except in the following contexts:

- in official names
- in abbreviations that are always written in all-caps
- when referring to code that uses all-caps
