## Overview

`ComponentWrapper` is a helper component intended for internal Reservoir Design
System (DS) use. It gives components such as `Checkbox`, `Select`, `TextInput`,
and `SearchBar` a consistent DOM structure: an optional heading, an optional
description, the wrapped children, and a `HelperErrorText` component.

The `HelperErrorText` container always renders, even when no helper or invalid
text is passed. This guarantees `aria-describedby` references never point to an
element that does not exist and that dynamic text updates are announced.

## Component props

`ComponentWrapper` composes a Chakra `Box` component, so you may pass any Chakra
`Box` props, as well as the props below.

## Heading and description

Use `headingText` to render a `Heading` above the children and `descriptionText`
to render a `Text` paragraph between the heading and the children.

<Canvas of={ComponentWrapperStories.HeadingAndDescription} />

## Invalid state

Set `isInvalid` to `true` to render `invalidText` instead of `helperText`, with
the invalid styling and icon from `HelperErrorText`.

<Canvas of={ComponentWrapperStories.InvalidState} />

## Hidden helper text

Set `showHelperInvalidText` to `false` to hide the helper or invalid text. The
`HelperErrorText` container still renders in the DOM.

<Canvas of={ComponentWrapperStories.HiddenHelperText} />

## JSX text

`descriptionText`, `headingText`, `helperText`, and `invalidText` accept either a
string or a JSX element.
