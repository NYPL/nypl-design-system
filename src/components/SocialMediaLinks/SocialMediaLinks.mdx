## Accessibility

Internally, links are organized in a `ul` list element using the
[List](./?path=/docs/components-typography-styles-list--docs),
[Link](./?path=/docs/components-navigation-link--docs), and
[Icon](./?path=/docs/components-media-icons-icon--docs) components.

If the `showLabels` prop is set to `false`, the labels are still visible to
screen reader software.

## `linksData` and available icons

The `linksData` prop accepts an array of objects. Each item requires the
properties: `icon`, `labelText`, and `url`. The `icon` property relates to the
icon rendered on page.

<Source
  code={`
  type IconNames =
    | "fileTypeGenericDoc"
    | "socialFacebook"
    | "socialInstagram"
    | "socialPinterest"
    | "socialSoundCloud"
    | "socialTikTok"
    | "socialTumblr"
    | "socialTwitter"
    | "socialX"
    | "socialYoutube";
  // ...
  interface SocialMediaLinkDataProps {
    icon: IconNames;
    labelText: string;
    url: string;
  }
`}
  language="tsx"
/>

All available icons:

<Canvas of={SocialMediaLinksStories.AllOptionsVariations} />

<Source
  code={`
  import {
    SocialMediaLinks,

  const myLinksData: SocialMediaLinkDataProps[] = [
    { icon: "socialX", labelText: "NYPL Educators", url: "https://x.com/NYPLEducators"},

  ];

## Responsive design

For any viewport less than or equal to the "md" breakpoint (currently 768px),
links _with labels_ will stack vertically and those _without labels_ will
align horizontally automatically. For any viewport less than or equal to the
`"md"` breakpoint, links will be center-aligned.

The minimum height is `44px` and the minimum width is `44px`, regardless of the
`size` prop value.
