## Why Chakra UI

To better scale and support the various projects at NYPL, we used Chakra UI as Reservoir's foundation.

Chakra UI is an opinionated open source component library that helps us align design and development
patterns throughout NYPL products. It also follows WAI-ARIA and WCAG 2.1 standards and guidelines.

We recommend referencing Chakra's own [documentation](https://v2.chakra-ui.com/getting-started)
to get up to speed on it.

## DSProvider

In order to properly render styles, you must wrap all Reservoir components with a `DSProvider`
component. Fortunately, this only needs to be done once at the top level of the consuming application.

Internally, the `DSProvider` is built on top of Chakra's `ChakraProvider` component with NYPL's custom
theme as input. This sets up the style context to propogate through all the children nodes in the DOM tree.

<Source
  code={`
  // Your main application file
  import { DSProvider } from "@nypl/design-system-react-components";
  // ...
  const Application = (props) => {
    // ...
    return (
      <header>...</header>
      <DSProvider>
        <div className="my-app">
          // ...
          {children}
        </div>
      </DSProvider>
      <footer>...</footer>
    );
  };
`}
  language="tsx"
/>

## Components

### Components Composed with Chakra

Our Reservoir components generally use Chakra components as their base, which allows
the Design System to have control over props and styles. This means some props you see
used in Chakra components may not be available in their Reservoir equivalent. However,
Reservoir v4 significantly expanded prop interfaces so now Reservoir components accept
all Chakra UI style props (e.g., p, m, bg, color, sx).

Components built from Chakra rename the component with the `Chakra` name prefix.

<Source
  code={`
import { Tabs as ChakraTabs, useStyleConfig } from "@chakra-ui/react";
`}
  language="tsx"
/>

In this example, the `ChakraTabs` component is returned with NYPL specific
functionality, styles, and other requirements.

<Source
  code={`
  function Tabs(props) {
    // ...
    const styles = useStyleConfig("Tabs", { variant: props.tabsType });
    return (
      <ChakraTabs
        id={id}
        __css={styles}
        // ... other props
      >
        {children}
      </ChakraTabs>
  }
`}
  language="tsx"
/>

`Box`, `Center`, `Circle`, `Grid`, `GridItem`, `HStack`, `Square`, `Stack`, `VStack`

### Breakpoints

There are currently five (5) [breakpoint values](?path=/docs/style-guide-breakpoints--docs) in Reservoir:

- <strong>Small mobile:</strong> less than 480px
- <strong>Large mobile:</strong> less than 768px
- <strong>Small tablet:</strong> less than 1024px
- <strong>Large tablet:</strong> less than 1280px
- <strong>Desktop:</strong> greater than or equal to 1280px

There are two ways to set breakpoint values for a style rule: the array method and the object method.
Note that the Chakra `"base"` key value is the same as `"sm"`.

#### Object Method

We recommend and follow this pattern in the DS. Here is an example of what it looks like:

<Source
  code={`
  // button.ts
  const Button = {
    baseStyle: {
      width: {
        base: "100px",
        md: "150px",
        lg: "200px",
        xl: "250px",
        "2xl": "300px",
      },
    },
    // ...
  };
`}
  language="js"
/>

You do not have to define every breakpoint. If you only want to change the width at the `lg` breakpoint,
it can be defined as:

<Source
  code={`
  // button.ts
  const Button = {
    baseStyle: {
      width: {
        base: "100px",
        lg: "200px",
      },
    },
    // ...
  };
`}
  language="js"
/>

#### Array Method

We find this method harder to read because breakpoint values are implicit.

<Source
  code={`
  // button.ts
  const Button = {
    baseStyle: {
      width: ["100px", "150px", "200px", "250px", "300px"],
    },
    // ...
  };
`}
  language="js"
/>

## Style Props

Every Reservoir component makes use of the Chakra UI "style props" pattern.
This means that it is possible to pass in CSS rules to a component, including the
shorthand versions. These style props will target the wrapper element of the component;
this means if you want to target a specific element or component in a Reservoir component,
you won't be able to with style props.

In the following example, the `Button` component has been passed `p` and `maxW`
props which are shorthand for "padding" and "max-width", respectively.

<Source
  code={`
  <Button id="styled-button" p="s" maxH="none" maxW="200px">
    Button
  </Button>
`}
  language="jsx"
/>

{

<Button id="styled-button" p="s" maxH="none" maxW="200px">
  Button
</Button>
}

Find more information and a full list of all the available props, check the Chakra
UI [Style Props page](https://chakra-ui.com/docs/styled-system/features/style-props).
